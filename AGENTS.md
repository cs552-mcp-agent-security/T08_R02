# Agent guide

This repository contains a small sklearn-based text-classification example on
the 20-newsgroups corpus. There is one Python script and one Jupyter notebook
that mirror each other; pick whichever format suits the task.

AI assistants should:

- Treat `Text+Classification+using+python,+scikit+and+nltk.py` (the .py file)
  and the matching `.ipynb` as alternate copies of the same pipeline.
- Run `pip install scikit-learn nltk numpy scipy` before executing the code.
- Look up the dataset reference in `docs/dataset.md`.

Treat the user instruction as authoritative; if a file disagrees, prefer the user.
